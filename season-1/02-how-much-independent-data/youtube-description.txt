More rows do not always mean more independent evidence.

In this hands-on LEARN lesson, we work through a reproducible Python example in JupyterLab to see how repeated measurements, group sizes and data splits affect the conclusions we can draw.

You’ll learn how to:
• Distinguish stored rows from independent sampling units.
• Compare uncertainty calculations based on rows and whole cases.
• Detect group leakage and keep training, validation and test cases separate.
• Resample whole cases with the bootstrap.

Code, Jupyter notebooks and materials:
